# HR Analytics Dashboard | Power BI

## Project Overview

The **HR Analytics Dashboard** is a data analytics project designed to analyze employee information, workforce distribution, and key HR metrics. It helps HR professionals understand employee trends, monitor workforce performance, and make data-driven decisions.

The dashboard transforms raw HR data into meaningful visual insights using Microsoft Power BI.

## Project Objectives

- Analyze employee demographics and workforce distribution.
- Track employee headcount and attrition trends.
- Identify departments with higher employee attrition.
- Understand employee distribution by age, gender, and job role.
- Monitor key HR performance indicators (KPIs).
- Support data-driven human resource management decisions.

## Tools and Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Microsoft Excel** – Data storage and preprocessing.

## Key Performance Indicators (KPIs)

The dashboard can include the following HR metrics:

- Total Employees
- Total Employees Who Left
- Employee Attrition Rate
- Average Employee Age
- Average Years of Experience
- Department-wise Employee Count
- Job Role-wise Attrition
- Gender-wise Employee Distribution

## Dashboard Features

### 1. Employee Overview
Provides an overview of the workforce, including total employees, gender distribution, and employee demographics.

### 2. Attrition Analysis
Analyzes employee attrition patterns and identifies departments and job roles experiencing higher employee turnover.

### 3. Department Analysis
Compares workforce distribution across departments to support resource planning.

### 4. Employee Demographics
Explores employee distribution by age group, gender, education, and job role, depending on the available dataset.

### 5. Interactive Visualizations
Includes interactive charts, slicers, cards, and filters to help users explore HR data from different perspectives.

## Business Insights

The project aims to help organizations:

- Identify potential employee retention challenges.
- Understand workforce distribution across departments.
- Recognize employee groups with higher attrition.
- Improve HR planning and resource allocation.
- Make informed decisions regarding employee engagement and retention.

## How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. If prompted, update the dataset file path.
5. Refresh the data if required.
6. Explore the dashboard using its filters and visualizations.
